# Dot's Southern Kitchen

My very first website, built for my first ever customer in 2014. Pure HTML, CSS, jQuery, and PHP — no frameworks. I recovered the source code page by page from the live domain while it was still active.

## About the Site

A restaurant website for Dot's Southern Kitchen in Las Vegas, NV. Dot's had two locations and was known for classic southern cooking. The site includes:

- Home page with category navigation
- Menu pages: Breakfast, Burgers & Appetizers, Salads, Down Home BBQ, Seafood, Home Made Desserts
- About page — the story of Dorothy "Dot" Noles
- Contact page with Netlify Forms integration and Google Maps

## Stack

- HTML5
- CSS3
- jQuery 1.10.2
- Lightbox 2.6
- Netlify (hosting + forms)
